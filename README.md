# 🚀 COLoad - Fast & Lightweight Video Downloader API

**COLoad**, popüler platformlardan (YouTube, TikTok, Instagram vb.) video ve ses içeriklerine ait indirme bağlantılarını ve medya bilgilerini hızlıca çekebilmeniz için tasarlanmış, **FastAPI** ve **yt-dlp** tabanlı açık kaynaklı bir REST API servisidir.

---

## ✨ Özellikler

* ⚡ **Yüksek Performans:** Python FastAPI altyapısı sayesinde asynchronous ve ışık hızında yanıt süresi.
* 🎥 **Geniş Platform Desteği:** YouTube, TikTok, Instagram ve yüzlerce desteklenen platform.
* 📊 **Zengin Medya Bilgisi:** Video başlığı, kapak fotoğrafı (thumbnail), video süresi, yayıncı bilgisi ve kullanılabilir format listesi.
* 🌐 **CORS Destekli:** Ön yüz (Frontend) uygulamalarınızdan doğrudan istek atmaya hazır yapıda.
* ☁️ **Bulut Dostu:** Render, Koyeb, Railway veya kendi VPS sunucunuzda kolayca yayınlanabilir.
